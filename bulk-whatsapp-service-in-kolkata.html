Shared Inbox and Agent Roles for Kolkata Teams

Kolkata's schools, clinics, retailers and service companies often start WhatsApp on one phone shared by several people. It works for a month, and then messages are missed, two staff answer the same customer and nobody knows who owns what.

The WhatsApp Business API removes that limit. Several agents can use the same business number from a web inbox, with each conversation assigned to someone. Managers can see who is handling what and how long customers wait.

Set up roles from the start. A front-desk agent may handle general questions, a billing agent handles payment queries, a senior agent handles complaints. Add labels such as new enquiry, awaiting payment or follow up, so the team can filter the inbox quickly.

Write down simple rules: the first reply within a set time, a handover note when a chat moves between agents, and a policy for messages that arrive after hours. Many Kolkata customers write in Bengali, so make sure at least one agent on every shift can respond in it. We can set up the inbox, define roles and train your team in a short session.
